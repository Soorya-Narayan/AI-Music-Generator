# AI-Music-Generator
AI Music Synthesizer is an interactive system that generates music based on user-selected mood, genre, and instrument inputs. It uses AI models to compose music in real time, controlled via hardware (Arduino/Raspberry Pi), and outputs the generated sound through connected speakers.
